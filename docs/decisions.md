## Design decisions

1. **QA agent** produces a verdict plus concrete missing-test specs; the Copilot coding agent writes the tests in the next `FIXING` iteration, so two agents never push to the same branch.
2. **"Why I'm stuck" note** is generated by Bedrock from gate findings and recent commits instead of starting another Copilot session.
3. **Copilot code review** comments block only on the first gate pass of a run; afterwards they are advisory.
4. **`NEEDS_INFO`** ends the execution; re-flagging the ticket starts a fresh run.
5. **Memory database** is Aurora Serverless v2 with the RDS Data API, so Lambdas need no VPC or NAT.
6. **Build tool** is Maven (multi-module, wrapper).
7. **Local-first testing**: unit tests without Docker, integration tests with Testcontainers, full local stack with LocalStack, WireMock and pgvector.
